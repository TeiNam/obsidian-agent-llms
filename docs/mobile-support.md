# 모바일 지원 안내

**0.7.15**부터 PC·휴대폰·태블릿을 지원한다. 동일한 플러그인에서 실행 기기에 따라 PC 전용 기능을 분리한다.

| 기능 | PC | 휴대폰·태블릿 |
| --- | --- | --- |
| AI 채팅, 볼트 검색, 노트 읽기·수정, 태그 생성 | 유지 | 공통 코드 사용 |
| Graph RAG, Second Brain, 할 일 관리 | 유지 | 공통 코드 사용 |
| 로컬 MCP 서버 실행·관리 | 유지 | 설정 숨김, 모듈 로드·서버 실행 제외 |
| 채팅 창 | 오른쪽 사이드바 | 오른쪽 사이드바 |
| Enter | 전송 | 줄바꿈 |
| API 키 저장 | 기존 OS 키체인 기반 로컬 파일 | Obsidian SecretStorage |

모바일에서는 전송 버튼 또는 Ctrl/Cmd+Enter로 메시지를 보낸다. 한글 조합 중 Enter 전송 방지는 유지한다. 좁은 화면에서는 헤더·도구 모음이 줄바꿈되며 주요 버튼의 터치 영역을 넓혔다.

초기 체험 버전에서 본문 영역에 열었던 채팅 탭은 한 번 닫고 다시 열면 오른쪽 사이드바에 표시된다. 이미 열린 대화를 자동으로 닫거나 재생성하지 않는다.

## 설치와 키 설정

1. 볼트에서 기존 플러그인을 끈다.
2. 기존 `.obsidian/plugins/agent-llms/`의 `main.js`, `manifest.json`, `styles.css`를 별도 위치에 백업한다.
3. 릴리스에서 내려받은 위 세 파일을 해당 플러그인 폴더에 덮어쓴다. `data.json` 등 기존 설정·데이터 파일은 지우지 않는다.
4. Obsidian을 다시 열고 플러그인을 켠다.
5. 모바일 설정에서 사용할 AI 제공자와 API 키를 입력한다. 앱을 완전히 종료했다가 다시 열어 키 유지 여부를 확인한다.

PC에서 빌드 파일을 동기화해 설치할 수도 있다. 이 경우 같은 볼트를 쓰는 다른 기기에도 새 버전이 적용될 수 있다. 되돌릴 때는 플러그인을 끄고 백업한 세 파일을 복원한다. BRAT 설치는 [README의 설치 안내](../README-KR.md#설치)를 따른다.

모바일 키 저장에는 **Obsidian 1.11.4 이상**이 필요하다. 각 기기에서 별도로 입력하며 플러그인은 새 키를 `data.json`에 평문으로 기록하지 않는다. 구버전이나 저장 실패 시 새 키는 현재 세션에만 남고 알림을 표시한다. 기존 PC용 암호문은 모바일 API 요청에 사용하지 않으며, PC의 마이그레이션을 위해 원본을 보존한다.

Ollama를 사용한다면 모바일에서 접근할 수 있는 서버 주소가 필요하다. 휴대폰에서 `localhost`는 그 휴대폰 자체를 가리킨다.

## 확인한 범위와 실기기 점검

자동 검사는 실제 플러그인 진입점을 번들로 만들어 Node.js 전역이 없는 모의 모바일 환경에서 실행한다. 다음 항목을 확인한다.

- 모바일·PC 초기화, 오른쪽 사이드바에서 채팅 열기·기존 대화 재사용, PC에서만 MCP 모듈 로드.
- MCP 없이 채팅 도구 루프로 노트를 읽고 수정하며 변경 이력을 기록하는 흐름.
- 모바일 API 키 저장·재로드·삭제, 저장 실패, 구버전의 세션 전용 동작, PC 암호문 보존.
- 모바일 MCP 설정 제외, 공통 설정 유지, Enter·한글 조합 처리.
- 태그 재생성 시 제목·공백·줄바꿈 보존.

2026-10-09 사용자가 모바일 실기기에서 정상 동작을 확인했다. 기종·OS·백엔드별 전체 조합의 검증 결과는 기록하지 않았으므로, 새 기기에 설치하면 다음 항목을 점검한다.

- 채팅·노트 수정·태그 생성, 실제 응답 스트리밍과 중지, 모델 목록 조회.
- 세로·가로 화면 및 키보드 표시 중 입력창과 전송 버튼 접근.
- 앱 재시작 후 키 유지, 같은 볼트를 쓰는 PC의 기존 키·MCP 동작.
- 실제 볼트 크기에서 검색·인덱싱 속도와 메모리 사용.

장시간 인덱싱·에이전트 작업의 모바일 백그라운드 지속 실행은 보장하지 않는다. 우선 앱을 전면에 둔 상태에서 시험한다.

## 개발자 확인

```sh
npm test
npm run lint -- --max-warnings 0
npm run build
git diff --check
```

빌드 결과인 `main.js`와 저장소의 `manifest.json`, `styles.css`가 설치 파일이다. 최소 Obsidian 버전은 1.7.2로 유지하며, 모바일의 영구 키 저장만 1.11.4 이상을 요구한다.
